# 安装（阶段 A）

## 1. 上游

- OpenWork: https://github.com/different-ai/openwork  
- 按其 README 安装（macOS / Windows / Linux）  

## 2. 本仓

```bash
git clone https://github.com/juanwan99/aivia-workbench.git
```

阅读 `docs/PROJECT-PLAN.md`，按金路径验收。

## 3. DeepSeek

1. 在 DeepSeek 开放平台创建 API Key  
2. 参考 `ops/deepseek.env.example`  
3. 按 OpenWork / OpenCode 当前版本文档填入模型提供商  
4. 跑 G0b / G1  

## 4. PIN

安装成功后在 `upstream/PIN.md` 记录：

- OpenWork tag/commit  
- OpenCode 版本  
- 系统与安装日期
