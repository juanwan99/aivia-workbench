## 3. 新建任务页结构（live-02）

- 场景 Tab：**日常办公 | 代码开发 | 设计创意**
- chip 行（办公例）：文档处理、金融服务、数据分析及可视化、个人工作台、深度研究、视频…
- Composer 内可出现 **可移除能力标签**（例：网站设计 ×）
- 底栏控件：**选择工作空间 ▾ · 默认权限 ▾ · Auto ▾ · 语音 · 发送**
- 「+」：组合绑定入口（历史截图 `wb-composer-add-menu`：文件/模式/专家/技能/连接器）

## 4. 任务完成页结构（live-08 真会话）

```text
标题 = 用户任务摘要
中区:
  用户气泡
  助手块:
    状态「已完成 Ns」
    正文 / 路径 / 内容
    文件卡 (name · size · 打开)
    链接: 查看所有产物 · 查看所有变更
    底条: 反馈图标 · 共消耗 X · Auto (实际模型)
右栏:
  浏览器 ▾
  产物 ▾ → 文件列表 (hello.txt)
底 Composer: 可继续多轮
```

**短答页（live-08b）：** 同样有「已完成 / 共消耗 / Auto(模型)」；**无文件卡、无强制产物**。

## 5. 能力中心（live-05）

- Tab：专家 | 技能 | 连接器  
- 精选场景卡片（投资/法律/小微/电商…）  
- 专家/专家团列表 + 分类条（全部、OPC、腾讯专家、**教育学习**、游戏…）  
- 搜索 +「我的专家」

## 6. 自动化（live-06）

- 顶：定时任务 | 运行记录  
- 空态 CTA「+ 添加自动化」  
- 模版网格（日报、周报、提醒、壁纸…）— **用户前台配置**；企业治理另见公开文

## 7. 项目组织（live-01/04）

- 四 Tab：动态 · 计划 · 任务 · 资产  
- 右轨「项目配置」：指令 / 连接器 / 专家 / 技能 / 自动化（均「+」绑定）  
- 顶「邀请」= 团队协作入口（个人号可见按钮；企业 RBAC 细项未进 Admin）

## 8. 与 Aivia Web 对照

| WB 壳 | Aivia 现行 |
|-------|------------|
| 六入口 + 侧栏任务列表 | 单公开 Chat 链 |
| 结果栏 浏览器/产物 | 回答内 `/dl` 链 |
| 完成块 耗时/消耗/模型 | 无统一 Run 卡 |
| 专家目录/自动化页 | 无 |
| 项目右轨绑定 | 无 |

## 9. 管理入口诚实声明

- **本机个人号：无独立企业管理后台整屏。**  
- 可见偏治理的 UI：默认权限、项目邀请、连接状态、用量消耗数字。  
- 组织/配额/审计细项 → 映射 Aivia **Admin/ops**，不塞老师 Chat。
