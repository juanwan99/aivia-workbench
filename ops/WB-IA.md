## 2. 导航树（用户前台）

```text
WorkBuddy Desktop
├── 新建任务          → 首页 Composer + 场景 chip + 灵感
├── 助理              → 助理态入口（与任务并列一级）
├── 项目              → 项目对象；内含 动态|计划|任务|资产 四 Tab（对齐调查）
├── 专家·技能·连接器  → 能力中心三 Tab
├── 自动化            → 定时/周期任务配置与运行记录
├── 更多
│   ├── 资料库·灵感
│   └──（公开文）我的文件 / 腾讯文档 / ima / 乐享 / 邮箱 等生态入口
├── 任务列表          → conversationId 历史；点开恢复
└── 空间              → 工作空间/项目绑定
```

## 3. Composer 组合输入模型（关键）

```text
ComposerDraft
├── text                 # 自然语言
├── attachments[]        # + → 添加文件
├── mode?                # + → 模式（ask/craft/coding/design… 模板侧）
├── expert?              # + → 专家
├── skill?               # + → 技能
├── connector?           # + → 连接器
├── workspaceId?         # 选择工作空间
├── permissionMode       # 默认权限 / 完全访问 等
└── modelId              # Auto 或指定模型
```

场景 chip **不是**纯文案：选中后出现可移除能力标签 + 刷新建议 + 相关灵感（`wb-home-design-chip-selected`）。

## 4. 任务进行中布局（行为）

- 中区：消息流（user / assistant / tool 轨迹在 transcript 落盘）  
- 右侧结果栏（宽约 322px）：**概览 · 工作空间文件 · 浏览器**（对齐调查实测）  
- 完成块可投影：耗时、消耗、实际模型（如 Auto→GLM-5.2）  
- 运行中可停止；停止后应有 cancelled 语义（产品侧）

## 5. 与 Aivia 信息架构对照

| WB | Aivia 现行 | 差距 |
|----|------------|------|
| 六一级入口壳 | 单公开 Chat 链 | 无项目/自动化/能力中心壳 |
| Composer 组合输入 | 文本 + 推荐问题 | 无 + 菜单绑定 |
| 结果栏三视图 | 回答内 `/dl` 链接 | 无文件树/浏览器结果 |
| 任务列表侧栏 | Dify 会话 | 无 Task/Run 投影 |
| 桌面工作空间 cwd | 云端无本地盘 | 桌面二期 |

## 6. 管理员入口

- **本机个人账号未观察到独立「企业管理后台」整屏。**  
- 企业版公开文：Admin = 组织/授权/审计/用量/模型资源（见 sources web）。  
- Aivia 映射：Dify Console + 自建 Admin/ops，**不**塞进老师 Chat。
