# OpenWork 安装（二期 · 可选 · 非主线）

```
STATUS: OPTIONAL · 本地文件增强
主线请用: ops/INSTALL.md（Dify Web）
正本: docs/CANON.md
```

OpenWork（https://github.com/different-ai/openwork）用于**本机**深文件处理，**不**作为学校默认公网入口，**不**与 Dify 双主线。

## 何时考虑

- 阶段 D 后，且主线浏览器 G1 已稳定  
- 明确需要本地工作区强写盘  

## 摘要步骤

1. 从官方 Releases 下载对应平台安装包  
2. 本机配置 DeepSeek（以 OpenWork/OpenCode 上游文档为准；可用 `/connect`）  
3. 验收仅作本地增强；**勿覆盖** `upstream/PIN.md` 主行的 Dify 钉  

若需 OpenCode 兼容 JSON 样例，自行按上游文档编写，**不要**再放回主线 `ops/` 根目录以免误导。
