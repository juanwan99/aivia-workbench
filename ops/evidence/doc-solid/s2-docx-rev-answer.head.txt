# 初中生物 · 细胞结构（第一课时·改稿）

## 一、教学目标

1. 说出细胞的基本结构（细胞膜、细胞质、细胞核）。
2. 描述动植物细胞结构的异同点。
3. 使用显微镜观察永久装片，识别细胞的基本结构。

## 二、教学重难点

- 重点：细胞的基本结构及其功能。
- 难点：动植物细胞结构的异同比较。

## 三、教学准备

- 显微镜、永久装片（人口腔上皮细胞、洋葱鳞片叶内表皮细胞）
- 多媒体课件、板书设计

## 四、教学过程

### （一）导入新课（5分钟）

展示显微镜下的细胞图片，提问：“这些小小的格子是什么？它们有什么作用？”引出课题。

### （二）讲授新知（20分钟）

1. **细胞膜**：保护细胞内部结构，控制物质进出。
2. **细胞质**：生命活动的主要场所，内含多种细胞器。
3. **细胞核**：含有遗传物质，是细胞的控制中心。

### （三）观察实验（10分钟）

学生分组使用显微镜观察永久装片，识别细胞膜、细胞质、细胞核，并绘制简图。

### （四）比较动植物细胞（5分钟）

| 结构 | 动物细胞 | 植物细胞 |
|------|----------|----------|
| 细胞壁 | 无 | 有 |
| 细胞膜 | 有 | 有 |
| 细胞质 | 有 | 有 |
| 细胞核 | 有 | 有 |
| 液泡 | 无（或小） | 有（大） |
| 叶绿体 | 无 | 有（部分细胞） |

### （五）课堂小结（5分钟）

回顾本节课核心知识：

1. 细胞的基本结构：细胞膜、细胞质、细胞核。
2. 植物细胞特有的结构：细胞壁、液泡、叶绿体。
3. 显微镜观察细胞时，注意区分不同结构。
