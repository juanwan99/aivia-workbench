📘 核心知识点
一般式 ax²+bx+c=0 (a≠0) 求根公式 x = [-b±√(b²-4ac)] / 2a 因式分解法 配方法 判别式 Δ
标准形式： ax² + bx + c = 0    (a ≠ 0)
求根公式： x = [-b ± √(b² - 4ac)] / 2a

🔍 判别式 Δ = b² - 4ac

Δ > 0 → 两个不相等的实数根；Δ = 0 → 两个相等实数根；Δ < 0 → 无实数根（初中阶段）。

✏️ 典型例题

① 因式分解法

例： x² - 5x + 6 = 0

→ (x-2)(x-3) = 0

∴ x₁ = 2, x₂ = 3

② 公式法

例： 2x² + 3x - 2 = 0

a=2, b=3, c=-2

Δ = 9 + 16 = 25

x = [-3 ± 5] / 4 → x₁=0.5, x₂=-2

🧠 配方法示例： x² + 6x - 7 = 0 → (x+3)² = 16 → x+3 = ±4 → x₁=1, x₂=-7

📝 随堂练习

1. 解方程： x² - 9 = 0

提示：因式分解 (x+3)(x-3)=0 → x=±3

2. 用公式法解： x² - 4x + 1 = 0

Δ=16-4=12 → x = 2 ± √3

3. 判断根的情况： 3x² + 2x + 1 = 0

Δ=4-12=-8 < 0 → 无实数根
