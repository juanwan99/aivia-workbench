📌 概念精讲

y = kx + b   (k ≠ 0)

一次函数：形如 y = kx + b（k、b为常数，k≠0）的函数。

  • 📈 k — 斜率（倾斜程度）
  • 📏 b — 截距（与y轴交点）
  • 🔹 当 b = 0 时，为正比例函数 y = kx

🧭 图像性质

  • ✔ 一条直线
  • ✔ k > 0 上升；k < 0 下降
  • ✔ |k| 越大，直线越陡
  • ✔ 过点 (0, b)，且与 y = kx 平行

▲ 示意图：k>0 时上升

✏️ 典型例题

例1 已知一次函数 y = 2x - 1

① 求与y轴交点 → 令x=0，得 y = -1

② 求与x轴交点 → 令y=0，得 x = 0.5

③ 画出图像 → 过 (0,-1) 和 (0.5,0)

例2 已知直线过 (1,3) 和 (2,5)，求解析式

解：设 y=kx+b，代入得

k+b=3，2k+b=5 → k=2, b=1

✔ 解析式：y = 2x + 1

🎯 随堂练习

  • 🔸 1. 一次函数 y = -3x + 2 的斜率是？ (-3)
  • 🔸 2. 函数 y = 0.5x 的图像经过哪几个象限？ (一、三)
  • 🔸 3. 若一次函数 y = kx - 4 过点 (2, 2)，则 k = ? (k=3)

💡 记忆口诀

“一次函数直线条，k定陡峭b定交；k正向上k负倒，b是y轴截距宝。”
