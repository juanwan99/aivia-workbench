一元二次方程

高一数学 · 基础模块 · 解法与判别式

学习目标

  • ✔ 掌握一元二次方程的标准形式 ax² + bx + c = 0 (a≠0)
  • ✔ 熟练运用因式分解法、配方法、公式法求解
  • ✔ 理解判别式 Δ = b² − 4ac 与根的关系
  • ✔ 能利用根与系数的关系（韦达定理）解决简单问题

核心知识点

标准形式

ax² + bx + c = 0 (a≠0)

a 为二次项系数，b 为一次项系数，c 为常数项。

判别式

Δ = b² − 4ac

Δ>0 两个不等实根；Δ=0 两个相等实根；Δ<0 无实根。

求根公式： x = (−b ± √Δ) / (2a)

三种核心解法

① 因式分解法

适用于方程可分解为 (mx+p)(nx+q)=0 的形式。例：x² − 5x + 6 = 0 → (x−2)(x−3)=0 → x=2 或 x=3

② 配方法

将方程化为 (x + m)² = n 的形式，再开平方。例：x² + 6x + 5 = 0 → (x+3)² = 4 → x = −1 或 x = −5

③ 公式法（通用）

直接代入求根公式，适用于所有一元二次方程。

典型例题

例1（公式法）： 解方程 2x² − 4x − 6 = 0
解：a=2, b=−4, c=−6 → Δ = (−4)² − 4·2·(−6) = 16 + 48 = 64
x = (4 ± 8) / 4 → x₁ = 3, x₂ = −1
例2（判别式分析）： 判断方程 x² + 2x + 5 = 0 根的情况
解：Δ = 4 − 20 = −16 < 0 → 无实数根（有两个共轭虚根，高中阶段说明无实根）
例3（韦达定理）： 已知方程 3x² − 6x + 2 = 0 的两根为 x₁, x₂，求 x₁ + x₂ 与 x₁·x₂
解：x₁ + x₂ = −b/a = 2，x₁·x₂ = c/a = 2/3

随堂练习

  2. 用配方法解：x² + 4x − 1 = 0
