📌 核心知识点

求根公式（一元二次方程 ax²+bx+c=0, a≠0）
\( x = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a} \)
判别式 Δ = b² − 4ac
• Δ > 0：两个不等实根   • Δ = 0：两个相等实根   • Δ < 0：无实根

🧮 例题精讲 · 新增2道

例题 1 · 系数为分数/根号

解方程：\( 2x^2 - 2\sqrt{2}x + 1 = 0 \)

【分析】 a = 2, b = −2√2, c = 1。直接用求根公式。

Δ = b² − 4ac = (−2√2)² − 4·2·1 = 8 − 8 = 0

因为 Δ = 0，方程有两个相等的实数根：

\( x = \dfrac{-b}{2a} = \dfrac{2\sqrt{2}}{4} = \dfrac{\sqrt{2}}{2} \)

∴ 根为 \( x_1 = x_2 = \dfrac{\sqrt{2}}{2} \) （也可写为 \( x = \frac{\sqrt{2}}{2} \)）

例题 2 · 含参数 · 判别式讨论

已知关于 \(x\) 的方程 \( x^2 - (2k-1)x + k^2 - k = 0 \)，
求证：无论 \(k\) 取何值，方程总有两个不相等的实数根。

【证明】 a = 1, b = −(2k−1), c = k² − k

Δ = b² − 4ac = [−(2k−1)]² − 4·1·(k² − k)

= (4k² − 4k + 1) − 4k² + 4k = 1

∵ Δ = 1 > 0 恒成立

∴ 无论 k 取何值，方程总有两个不相等的实数根。（求根公式也适用：\(x = \frac{2k-1 \pm 1}{2}\)，得 \(x_1 = k, x_2 = k-1\)）

📐 经典例题回顾

例题 3 · 标准形式

解方程：\( 3x^2 - 4x - 2 = 0 \)

a=3, b=−4, c=−2

Δ = (−4)² − 4·3·(−2) = 16 + 24 = 40

\( x = \dfrac{4 \pm \sqrt{40}}{6} = \dfrac{4 \pm 2\sqrt{10}}{6} = \dfrac{2 \pm \sqrt{10}}{3} \)

\( x_1 = \frac{2 + \sqrt{10}}{3}, \quad x_2 = \frac{2 - \sqrt{10}}{3} \)

📝 小结 & 易错提醒

✅ 使用步骤
  • 化为一般式 ax²+bx+c=0
  • 确定a,b,c（注意符号）
  • 计算 Δ = b²−4ac
  • 代入公式，化简结果
⚠️ 常见失误
  • 漏写负号（尤其b为负）
  • Δ<0 时误写实根
  • 未约分（如√8 未化为2√2）

✏️ 随堂小练

1. 用求根公式解：\( x^2 - 5x + 3 = 0 \)

2. 解方程：\( 2x^2 + 4x - 1 = 0 \)（结果保留根号）

（答案：1. \(x=\frac{5\pm\sqrt{13}}{2}\)；2. \(x=\frac{-2\pm\sqrt{6}}{2}\)）
