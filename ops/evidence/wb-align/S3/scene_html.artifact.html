🎯 学习目标 3 个核心

📌 概念理解

掌握一次函数 y = kx + b (k≠0) 的结构，理解常量与变量的关系。

📌 图像与性质

能画出一次函数图像，理解 k（斜率） 与 b（截距） 对直线的影响。

📌 实际应用

用一次函数解决行程、费用、方案选择等简单实际问题。

🧠 核心知识点 重点
y = kx + b  (k ≠ 0)

k — 斜率（倾斜程度）
b — 截距（与y轴交点）

  • k > 0 直线上升（↗）
  • k < 0 直线下降（↘）
  • b > 0 交于y轴正半轴
  • b < 0 交于y轴负半轴

📐 图像特征

一次函数图像是一条直线。
两点确定一条直线：通常取 (0, b) 和 (-b/k, 0)。

⭐ 当 b=0 时，成为正比例函数 y=kx，图像过原点。

✏️ 典型例题 2 个经典

例1 · 求解析式：已知一次函数图像经过点 A(1, 3) 和 B(-1, -1)，求该函数表达式。

✅ 解：设 y = kx + b，代入两点：
k + b = 3 ① ； -k + b = -1 ②
① - ② 得 2k = 4 → k = 2，代入①得 b = 1。
∴ 解析式为 y = 2x + 1

例2 · 图像应用：一次函数 y = -2x + 4，求与x轴、y轴交点坐标，并判断经过哪几个象限。

✅ 解：令 x=0 → y=4 → (0, 4)；令 y=0 → -2x+4=0 → x=2 → (2, 0)。
k=-2 < 0, b=4 > 0 → 直线经过 一、二、四象限。

⚠️ 易错提醒 & 小结

🔍 常见错误

  • 忽略 k ≠ 0 的条件
  • 画图时误将直线画成线段
  • 混淆斜率k与截距b的几何意义

📘 课堂小结

一次函数 y=kx+b (k≠0) 是刻画变量关系的基础模型。
k 决定增减性，b 决定与y轴交点。利用两点法快速作图，结合实际问题建立函数关系。
