**一元二次方程 · 5 条核心知识点大纲**

1. **定义与一般形式**
   - 只含一个未知数，且未知数的最高次数为 2 的整式方程。
   - 一般形式：ax² + bx + c = 0（a ≠ 0），其中 a、b、c 为常数。

2. **解法（四大方法）**
   - 直接开平方法：适用于 (x + m)² = n（n ≥ 0）的形式。
   - 配方法：通过配方转化为完全平方形式，再开平方求解。
   - 公式法：求根公式 x = [-b ± √(b² - 4ac)] / 2a（万能解法）。
   - 因式分解法：将方程化为两个一次因式乘积为 0 的形式。

3. **根的判别式（Δ = b² - 4ac）**
   - Δ > 0：方程有两个不相等的实数根。
   - Δ = 0：方程有两个相等的实数根（即一个实数根）。
   - Δ < 0：方程没有实数根（有两个共轭虚根）。

4. **根与系数的关系（韦达定理）**
   - 若 x₁、x₂ 是方程 ax² + bx + c = 0 的两根，则：
     - x₁ + x₂ = -b/a
     - x₁ · x₂ = c/a
   - 常用于已知一根求另一根，或构造新方程。

5. **实际应用与解题步骤**
   - 常见题型：增长率问题、面积问题、利润问题、动点问题等。
   - 通用步骤：审题设未知数 → 列方程 → 解方程 → 检验根的合理性（是否满足实际意义）→ 作答。
