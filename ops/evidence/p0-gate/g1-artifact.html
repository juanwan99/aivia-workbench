光合作用

🎯 学习目标

  • 理解光合作用的概念、原料与产物
  • 掌握光合作用的反应式及物质转化
  • 认识光合作用对生物圈和人类的意义
  • 能运用光合作用原理解释生活现象

📘 核心知识

🌱 什么是光合作用

绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存能量的有机物（主要是淀粉），并释放出氧气的过程。

📍 场所：叶绿体
📍 条件：光照
📍 原料：CO₂ + H₂O

⚗️ 反应式

CO₂ + H₂O ☀️光能 → (CH₂O) + O₂

（有机物以葡萄糖C₆H₁₂O₆为例）

6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂

🔄 物质变化

无机物 → 有机物
（CO₂、H₂O → 淀粉等）

⚡ 能量变化

光能 → 化学能
（储存在有机物中）

🌍 光合作用的意义

  • 制造有机物 —— 为植物自身及动物、人类提供食物
  • 转化并储存太阳能 —— 是生物圈能量的根本来源
  • 维持大气中氧气和二氧化碳平衡
  • 对自然界的碳-氧平衡至关重要

📌 小结

  • 光合作用 = 光能 + CO₂ + H₂O → 有机物 + O₂
  • 在叶绿体中进行，需要光照
  • 原料：二氧化碳、水；产物：有机物（淀粉）、氧气
  • 意义：物质基础、能量来源、维持碳氧平衡

📝 课堂练习

1️⃣ 光合作用的产物是（　　）

A. 二氧化碳和水 B. 有机物和氧气 C. 无机盐和水 D. 氧气和二氧化碳
✅ 正确：光合作用产生有机物（储存能量）并释放氧气。

2️⃣ 在光合作用实验中，将天竺葵暗处理一昼夜的目的是（　　）

A. 消耗叶片中的水分 B. 消耗叶片中的叶绿素 C. 消耗叶片中原有的淀粉 D. 增加叶片中的氧气
✅ 正确：暗处理让叶片中原有淀粉运走耗尽，避免干扰实验检测新生成的淀粉。
