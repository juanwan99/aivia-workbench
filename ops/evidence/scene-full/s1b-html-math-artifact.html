📐 一次函数 · 初中数学

八年级 · 人教版 理解 · 图像 · 应用

🎯 学习目标

  • ✔ 理解一次函数的概念及一般形式
  • ✔ 掌握一次函数图像的特点（直线）
  • ✔ 理解斜率 k 和截距 b 的几何意义
  • ✔ 能根据条件求一次函数解析式
y = kx + b (k ≠ 0)

特别地，当 b = 0 时，是正比例函数 y = kx。

📈 图像与性质

k > 0 上升 k < 0 下降

k 决定直线的倾斜方向；b 决定与 y 轴交点 (0, b)。

⭐ 两点确定一条直线：通常取 (0, b) 和 (-b/k, 0)

🧩 典型例题

例1：已知一次函数图像经过 (0, 2) 和 (1, 5)，求解析式。

解：设 y = kx + b，代入 (0,2) 得 b=2；代入 (1,5) 得 k+2=5 → k=3。
∴ y = 3x + 2

例2：函数 y = -2x + 4 与 x 轴交点坐标？

解：令 y=0 → -2x+4=0 → x=2，交点 (2, 0)。

📝 随堂练习 · 小试牛刀

  • 1️⃣ 一次函数 y = 5x - 3 的斜率 k = ____，截距 b = ____。
  • 2️⃣ 函数 y = -x + 2 的图像经过哪几个象限？
  • 3️⃣ 已知 y 与 x 成正比例，且当 x=2 时 y=6，求 y 与 x 的函数关系式。
  • 4️⃣ 若点 (3, m) 在直线 y = 2x - 1 上，则 m = ____。
📌 参考答案（点击展开）

1. k=5, b=-3
2. 第一、二、四象限
3. y = 3x
4. m = 5

📌 小结

一次函数 y=kx+b (k≠0) · 图像是直线 · k 定方向，b 定截距
