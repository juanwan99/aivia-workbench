## 一元二次方程 · 学习要点

### 一、定义与标准形式
- **标准形式**：`ax² + bx + c = 0`（其中 `a ≠ 0`，a、b、c 为常数）
- 关键判断：**最高次数为 2**，且二次项系数不能为 0
- 注意：缺项（b=0 或 c=0）仍是一元二次方程，如 `x² - 4 = 0`

### 二、解法（四大方法）
1. **直接开平方法**
   - 适用：形如 `(x + m)² = n`（n ≥ 0）
   - 结果：`x = -m ± √n`

2. **配方法**
   - 步骤：移常数项 → 二次项系数化为 1 → 两边加一次项系数一半的平方 → 配方成完全平方 → 开方求解
   - 核心：`x² + px` 配成 `(x + p/2)² - (p/2)²`

3. **公式法（万能）**
   - 判别式：`Δ = b² - 4ac`
   - 求根公式：`x = [-b ± √(b² - 4ac)] / (2a)`
   - Δ > 0：两个不等实根；Δ = 0：两个相等实根；Δ < 0：无实根（有虚根）

4. **因式分解法**
   - 适用：方程可分解为 `(x - m)(x - n) = 0`
   - 原理：乘积为 0，则至少一个因式为 0
   - 常见：提公因式、十字相乘法、平方差、完全平方

### 三、判别式 Δ 的应用
- **判断根的情况**（见上）
- **求参数范围**：如方程有实根 → Δ ≥ 0；有两个不等实根 → Δ > 0
- 注意：二次项含参数时，要讨论 `a = 0` 与 `a ≠ 0`

### 四、根与系数的关系（韦达定理）
- 若 `x₁、x₂` 是方程 `ax² + bx + c = 0` 的两根，则：
  - `x₁ + x₂ = -b/a`
  - `x₁ · x₂ = c/a`
- 常见变形：
  - `x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂`
  - `(x₁ - x₂)² = (x₁ + x₂)² - 4x₁x₂`
  - `1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂)`

### 五、实际应用（列方程解应用题）
- 常见模型：
  - 增长率/降低率问题：`a(1 ± x)² = b`
  - 面积问题（矩形、围栏、小路）
  - 利润问题（单价调整、销量变化）
  - 握手/比赛场次问题：`n(n-1)/2 = 总数`
- 步骤：审题 → 设未知数 → 列方程 → 解方程 → 检验（舍去不合题意的根）→ 作答

### 六、易错点提醒
1. 忘记把方程化为一般形式再求 a、b、c
2. 用公式法时，`b² - 4ac` 计算符号出错
3. 因式分解后漏解（如只写一个根）
4. 应用题忘记检验根是否符合实际（如人数、长度不能为负）
5. 配方法中忘记两边同时加
