## 1. 部署（源站 ECS）

```bash
cd /path/to/aivia-workbench   # git pull 后
sudo mkdir -p /var/www/aivia-experts
sudo cp -a /var/www/aivia-experts/index.html \
  /var/www/aivia-experts/index.html.bak.$(date +%Y%m%d%H%M) 2>/dev/null || true
sudo cp deploy/aivia-experts/index.html /var/www/aivia-experts/index.html
sudo chmod 644 /var/www/aivia-experts/index.html
# nginx 已配置 alias 则 reload 即可；配置见 evidence/quad-fix-deploy/edge/workbench-experts.nginx.conf
sudo nginx -t && sudo systemctl reload nginx
```

若边缘机另有静态副本：对 asyncova 边缘重复 copy。
