## 0. 深度问题分析（为何要 Harden）

| 层 | 已有 | 缺口 | 若不修 |
|----|------|------|--------|
| 纪律 | 10 次空成功 0 | 依赖 Prompt + 代码块自觉 | 模型一漂又空成功 |
| 交付形态 | 可复制 HTML | 非平台 Artifact 下载 | 不像专业台；老师懵 |
| 配额 | max_tokens | 无日限额/真超时策略 | 账单与滥用风险 |
| 入口 | 域名有了 | 自签 + 可能 403 | 教师打不开/不敢进 |
| 教案 | MD | 非学校常用 DOCX | B2 完整度不足 |
| 治理 | PIN/RUNBOOK 有 | 真源仍指向「去做 B」 | 新窗重复劳动/假进度 |

**设计原则：**

1. **运行时变硬** > 再写文档  
2. **文件节点/附件** > 纯代码块（能上则上；Dify 能力边界内）  
3. **证书/WAF** 与应用硬化可并行，但**对外叙事绑死 H2**  
4. 回归：**抽测 5 次**（不是再刷满 10，除非 H1 大改出件路径）  
5. 仍禁止：fork 核、OpenWork 主线、edu 写库、密钥进仓

## 1. 工作包（按优先级）

### H0 · 真源收口（文档，先做防乱）

- [x] 本包 + CLOSEOUT 落盘  
- [ ] HANDOFF / CANON / README / PROJECT-PLAN：B 有条件绿；下一刀 = **B-HARDEN**  
- [ ] PIN：B3=PARTIAL；链到 CLOSEOUT  
- [ ] Issue 标题/评论： Harden 任务卡  

**验收：** 新窗 30 秒看出「B 电池已跑、在硬化，不是重装」。

### H1 · 交付形态硬化（对标专业台 · 最高优先应用侧）

**目标：** 用户终态能 **一键下载文件**，而不是「请复制下面代码自行保存」作为唯一路径。

可选实现（按 Dify 1.16 实际能力选最硬者）：

| 方案 | 做法 | 硬度 |
|------|------|------|
| 甲 | Chatflow 增加 **代码执行/文件** 节点，写出 `.html` 到文件变量，Answer 绑定文件 | 最硬 |
| 乙 | HTTP/工具节点生成文件 URL | 硬 |
| 丙 | 保留代码块但 **强制** 页内 data-URL 下载按钮 + 禁止无按钮终态（A 阶段形态） | 底线 |

**最低通过：** 新会话 T1 类话术 → 用户不经「全选复制」也能得到 `.html` 文件（附件或明确下载控件）。  
**失败定义：** 仅长代码墙且无下载控件 = Harden FAIL。

回归：T1、T2（改稿）、T8 各 1 次。

### H2 · 入口硬化（证书 + 公网 · 运维）

= A 残留 R-A1 + R-A2。

**未过 H2：** 可对内演示；**禁止**「教师正式使用」话术。

### H3 · 真配额 / 超时（纠正 B3）

| 旋钮 | 建议起点（与业主可调，必须写进 Issue） |
|------|------------------------------------------|
| 应用/工作空间 **日消息或 token 上限** | 先定试点数字，如日 200 条/用户或工作空间级 |
| 请求超时 | 按 Dify 应用配置可感知值 |
| 超限提示 | 人话：「今日额度已用完，请明日或联系管理员」 |

**验收：**  
1. 配置项截图或文字（无密钥）进 Issue  
2. **至少一次**触发或模拟超限 → 人话，不假绿  
3. PIN/CLOSEOUT 将 B3 改为 **PASS** 仅当上述满足  

### H4 · 教案 DOCX（或诚实缩 scope）

二选一（写进 Issue）：

- **做实：** 工具/转换出 `.docx` 可下载（一轮 T4 回归）  
- **缩 scope：** 明文「v0.x 教案=MD，DOCX 后置」并更新 skills/lesson-plan  

禁止：口头说支持 DOCX 实际只有 MD。

### H5 · 单主入口

- 教师文档/欢迎语/README **只推** `.../chat/lOMVPbz7rZmbJSJl`  
- 旧 Agent 链标注「备用/排障」或下架公开  
- 控制台应用排序：Aivia 课件置顶  

### H6 · 证据抽检

- 从服务器产物中选 **2 个 HTML + 1 个教案** 做结构抽检记录（文件名+是否可开）进 Issue  
- **不要**把含隐私的全文强行进 Git；可放脱敏截图  
- 可选：`ops/fixtures/` 放 1 个无版权问题的样例 HTML 壳（非必须）  

### H7 · 回归电池（抽测 5）

H1 完成后必跑：

| # | 话术 | 期望 |
|---|------|------|
| R1 | 豌豆杂交 HTML 下载 | 真下载/附件 |
| R2 | 同会话加 2 题再导出 | 仍有文件 |
| R3 | 只要大纲不要文件 | 无假文件成功 |
| R4 | G4 类失败 | 不假绿 |
| R5 | 极短「课件」 | 默认主题出件或澄清 1 次后出件 |

空成功必须 0。全过 → Harden 应用侧绿。
