## 0. 一线对标尺（评审用 · 每条任务对照）

| 一线行为（WorkBuddy 类） | 本卡怎么验 | 不及格样例 |
|--------------------------|------------|------------|
| 受理后真执行非闲聊 | 有结构化产物或完整正文 | 只客套、只提纲敷衍（用户已要求成稿/文件时） |
| 有产物可打开 | `/dl` 200 + 本地打开 + 正文相关 | 链接 404、空包、坏 OOXML、文不对题 |
| 无产物路径干净 | 短答/「不要文件」零 DOWNLOAD | 硬塞文件卡、假 DOWNLOAD_READY |
| 同会话可迭代 | G4 第二轮完整 v2 | 「已按要求修改」无新文件/无全文 |
| 状态诚实 | 做不到说原因 | 「已完成」却无下载 |
| 通用入口 | 四域任务同一 Chat | 必须换「教育专家」才能干活 |

**铁律：** 工程脚本绿但浏览器打不开 / 内容离谱 = **FAIL**。  
**铁律：** 只有 G8 教育绿 = **不得** CLAIM-GENERAL-WB。

## 1. 测句与过线（必须可复现）

统一：默认入口 Chat · 新会话起 G4；G5–G7 可各新会话。  
API 用户 id 固定前缀 `s2-battery-` 便于日志。

### G4 · 同会话改稿（对标 B-08）

| 轮 | 用户输入（一字不差） | PASS |
|----|----------------------|------|
| R1 | `请生成一份《项目启动会纪要》Word 文档（必须可下载 docx）。含：会议信息、决议列表、待办（事项/负责人/日期）。` | 出现 `https://asyncova.com/dl/.../file.docx`（或现网等价）；HTTP 200；ZIP 含 `word/document.xml`；正文含纪要结构（会议/决议/待办） |
| R2（**同一 conversation**） | `请在上一版基础上改一版完整文档（不要只给 diff）：1) 标题改为《项目启动会纪要-v2》2) 待办表增加「优先级」列 3) 仍给我可下载的 docx。` | **新** `/dl`（id 可不同于 R1）或明确新文件；可下可开；标题/优先级体现；**禁止**仅文字「已改」无文件 |

**G4 FAIL：** 第二轮无文件；只有 diff；仍下载到 R1 同一空改文件；会话断了算未测同会话。

### G5 · 公众号/传播文案

| 输入 | PASS |
|------|------|
| `写一篇公众号推文正文：《远程办公的 5 个效率习惯》。要求：标题+导语+5 个小标题要点+结尾互动句；800 字内；只要正文，不要生成任何文件。` | 完整成稿（标题+5 习惯+互动）；可读中文；**无** `/dl`、**无** `DOWNLOAD_READY`、**无**「交付文件」行；非三行敷衍 |

**加严（同会话可选抽检，不过线也可记加分）：**  
再发：`改成 markdown 文件可下载`。若做：须真 `/dl`；若不做：须诚实说能力边界（不得假绿）。

### G6 · 编程交付

| 输入 | PASS |
|------|------|
| `写一个可运行的 Python3 脚本：从标准输入或同目录 data.csv 读取 CSV（首行为表头），打印每一数值列的均值；缺省文件则内置 3 行示例数据演示。请给出完整脚本（可复制代码块，或 .py 可下载二选一，须完整可运行）。` | 完整脚本（有 import/读入/计算/输出）；复制后逻辑自洽；若给文件则 `/dl` 真文件；禁止伪代码省略号糊弄关键逻辑 |

**加严（推荐执行，记入证据）：** 将代码保存跑通 `python3 script.py` 退出码 0（执行窗本机）。跑不通但代码明显可修 → **COND**；明显不可运行 → **FAIL**。

### G7 · 分析结构化（禁投资承诺）

| 输入 | PASS |
|------|------|
| `请根据下列假设数据做竞品对比，输出 Excel 可下载：产品A 单价99元 月销量120；产品B 单价79元 月销量200。表至少含：产品、单价、月销量、估算月营收。再给 3 条中性观察（不要投资建议、不要荐股、不要「稳赚」话术）。` | `/dl` 真 xlsx；`xl/` OOXML；表含要求列与两行产品+营收合理；正文/表侧观察中性；**禁止**荐股/稳赚/保证收益 |

### G8 · 可选加分（永不单独过线）

| 输入 | 说明 |
|------|------|
| `做一份初中生物「豌豆杂交」单页 HTML 课件，要能下载。并声明：此为通用能力示例，不依赖 edu-core 写库。` | 最多加分；**不能**代替 G4–G7 |
