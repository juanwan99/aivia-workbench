## 状态机（UI 可见）

```text
空闲 → 用户发任务/选 chip
  → 受理（新会话进「任务」列表；绑定 workDir）
  → 执行（可工具循环；UI 等待态）
  → 完成「已完成 Ns」
        ├─ 有产物: 文件卡 + 右栏产物 + 查看所有产物/变更
        └─ 无产物: 纯文本（短答）
  → 摘要条: 共消耗 X · Auto (实际模型)
可选: 停止（本 live 未新跑停止用例）· 同会话续聊
```
