# 课件 HTML

## 目标

根据用户给出的学科与主题，生成**单文件 HTML 课件**（可含内联 CSS），并**写入工作区磁盘**。

## 强制纪律（空成功禁止）

1. 需要课件时，**最后一步必须调用写文件工具**（write / 等价工具）。
2. 成功标准：**工作区存在 `.html` 文件**，并在回复中给出相对或绝对路径。
3. 若写盘失败：明确报失败，不得标记任务成功。
4. 不要用「下面是代码请自行保存」代替写盘。

## 流程

1. 确认主题（学科 + 课题）。缺省时用用户原话作标题，并选合理默认年级。
2. 规划结构：标题、学习目标、知识点分节、小结、可选练习题。
3. 生成完整 HTML5（`<!DOCTYPE html>`、viewport、可读排版）。
4. 文件名：`课件-<简短主题>.html` 或用户指定名；避免覆盖未确认的重要文件。
5. **写盘** → 回复路径 + 一句话打开方式（浏览器打开该文件）。

## 内容要求

- 中文为主（用户要求其他语言除外）
- 知识点正确、简洁，适合课堂投影
- 避免外链脚本；样式内联或同一文件内 `<style>`
- 生物「豌豆杂交」等主题：包含孟德尔实验要点、性状、分离比示意（可用简单表格）

## 示例触发

- 「做一份生物豌豆杂交的 HTML 课件」
- 「课件：初中物理 牛顿第一定律」
