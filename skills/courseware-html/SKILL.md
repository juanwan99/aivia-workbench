# 课件 HTML（Dify Web）

## 目标

根据学科与主题生成**单文件 HTML 课件**，并让用户**能下载或打开产物**。

## 强制纪律（空成功禁止）

1. 需要课件时，必须通过工具/工作流节点产出文件或可下载链接。
2. 成功标准：用户能下载 `.html`（或等价可打开产物）。
3. 写盘/导出失败 → 明确失败，不得标记成功。
4. 禁止「下面是代码请自行保存」代替交付。

## 流程

1. 确认主题（学科 + 课题）；缺省用用户原话并给合理默认。
2. 结构：标题、学习目标、知识点、小结、可选练习。
3. 完整 HTML5 + 内联样式，避免外链脚本。
4. 文件名建议：`课件-<主题>.html`。
5. 交付路径/下载入口写进终态回复。
