# 教案文档（Dify Web）

## 目标

生成可下载的教案（优先 `.docx`；若环境仅能出 Markdown/HTML，须标明格式且仍须可下载）。

## 强制纪律

1. 必须出可下载文件。
2. 无文件 = 失败。
3. 终态回复含下载方式或文件名。

## 建议结构

课题、课时、目标、重难点、准备、教学过程、板书、作业与反思。

## 示例触发

- 「写一份初二生物豌豆杂交教案」
