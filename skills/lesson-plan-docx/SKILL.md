# 教案 DOCX

## 目标

生成可在 Word / WPS 打开的**教案文档**，并**写入工作区**。

## 强制纪律

1. 需要教案文件时，必须使用可生成 `.docx` 的工具或脚本写盘。
2. 若环境暂无 DOCX 工具：先生成结构化 Markdown/HTML 并写盘，**明确说明**尚非 docx，状态为部分完成而非假成功；有工具则优先 docx。
3. 成功回复必须包含产物路径。
4. 无文件 = 失败。

## 建议结构

1. 课题 / 课时 / 年级
2. 教学目标（知识、能力、素养）
3. 教学重难点
4. 教学准备
5. 教学过程（导入 → 新授 → 练习 → 小结）
6. 板书设计
7. 作业与反思

## 流程

1. 收集课题与学段；缺省用合理默认并在文中标明。
2. 按结构填充具体内容（避免空洞套话）。
3. 写盘：`教案-<课题>.docx`（或 `.md` 回退）。
4. 回复路径与打开方式。

## 示例触发

- 「写一份初二生物豌豆杂交教案 docx」
- 「教学设计：分数加减法 一课时」
