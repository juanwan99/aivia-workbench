## 0. 约束

| 必须 | 说明 |
|------|------|
| **Web** | 登录即用，挂现有 IP/域名 |
| Agent/工具 | 非纯闲聊；能出文件/工作流 |
| DeepSeek | API 可接 |
| 自托管 | Docker 优先 |
| 多用户潜力 | 教师账号 / 日后 edu |
| 中心化库/模板 | 云端治理优于老师本机建库 |

**OpenWork：** 桌面成品，**不作云端主路径**；二期可选本地增强。

---

## 1. 候选池（Web 向）摘要

| 项目 | 形态 | 云端主路径适配 |
|------|------|----------------|
| **Dify** | Web 应用/工作流/Agent | **★★★★★ 主选** |
| Open WebUI | Web AI 总台 | ★★★★ |
| LibreChat | Web 多模（Pico 曾用壳） | ★★★★（有历史债） |

| **OpenWork** | **桌面** | ★★ **二期** |

---

## 2. 结论（已确认）

| 项 | 决定 |
|----|------|
| 云端优先 | **是** |
| 主底座 | **Dify Web** |
| 模型 | **DeepSeek** |
| 部署 | 现网 Docker + 域名反代 |
| OpenWork | **二期可选**，非主线 |
| Spike | 以现网实装 Dify+DS+G1 为确认；对照栈非必须 |

### 推荐架构

```text
现有服务器 + 域名
    │
    ▼
Dify（Web 主台：应用/Agent/工作流/知识库）
    │
    ├── DeepSeek API
    ├── 文档工具（HTML/DOCX/PPTX → 可下载）
    ├── 中心知识库/模板
    └── 后置：edu JWT、OnlyOffice（可选）

二期：OpenWork/桌面（本地深文件）
```

**交付硬规则独立于厂商：** 要文件必须有文件。
