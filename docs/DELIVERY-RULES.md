# 交付硬规则（阶段 B · B1）

来源：`docs/RESPONSE-LOGIC.md` R1–R8。对标 WorkBuddy **行为**，不抄闭源。

| # | 规则 | 落地方式（优先配置/Skill，禁止重写 OpenCode 核） |
|---|------|--------------------------------------------------|
| R1 | 用户目标优先任务化 | 默认 Agent 提示：可执行任务优先于闲聊结束 |
| R2 | 信息足够则执行；禁止「只反问」当成功 | Skill 写明：缺关键参数最多澄清 1 次，然后给默认并执行 |
| R3 | 需要文件/课件 → 必须工具写盘 | **课件/教案 Skill 强制最后一步 write 工具** |
| R4 | 成功 ⇒ 可定位 Artifact；否则 failed | 终态文案必须含产物路径或明确失败；禁止空成功 |
| R5 | 过程可见 | 依赖 OpenWork 工具步展示；不隐藏写盘 |
| R6 | 工作区边界默认生效 | 仅写当前 workspace；不越权 |
| R7 | 可停、可再试 | 使用上游停止能力；失败提示可重试 |
| R8 | 终态人话，禁止假绿 | 无文件 = 失败/需重试，不得标完成 |

## 验收尺子（B 出口）

多轮「要课件」**10 次**，空成功 = **0**。

判定：每次要求文件类产物时，工作区或产物区必须有可打开文件；否则记 FAIL。

## 配额 / 超时 / 步数（B3）

在 OpenWork / OpenCode 当前版配置中设置（字段名随上游）：

- 单任务最大步数
- 工具调用超时
- 日/会话 token 或请求上限（若有）

本仓不绑定具体数字；试点前由业主定「防烧钱」上限并记入 Issue。

## 品牌（B4，可选）

仅应用名 / 关于文案；**不改**任务–工作区主交互骨架。

## 禁止

- 为像素抄 WB 大改 UI
- 无 G1 证据宣称「已对标完成」
- Agent 直写 edu 业务库
