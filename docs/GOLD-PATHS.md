# 金路径验收

模型：DeepSeek。环境：OpenWork 本机。

| ID | 步骤 | 通过标准 |
|----|------|----------|
| **G0** | 安装并打开 OpenWork | 主界面可用 |
| **G0b** | 配置 DeepSeek | 短聊「只回：好」成功 |
| **G1** | 「在工作区写 hello.txt，内容 hi」 | 磁盘有文件，内容正确 |
| **G2** | 多轮：先问能否做课件 → 再给「生物 豌豆杂交 HTML」 | **有 .html 产物可打开**；不得仅聊天成功 |
| **G3** | 运行中停止（若支持） | 停止后不再继续写盘或状态为取消 |
| **G4** | 故意要文件但中断/失败 | **不显示成功无文件** |
