# 金路径验收（浏览器 / Web）

```
模型：DeepSeek
环境：现网 Dify Web（HTTPS 子域或服务器 URL）
UPDATED: 2026-08-05 · 阶段 A 出口 = G0+G0b+G1+G1+；对标主流站最小交付真相
```

| ID | 步骤 | 通过标准 |
|----|------|----------|
| **G0** | 浏览器打开工作台 URL | 登录页/主界面可用 |
| **G0b** | 已配 DeepSeek；短聊「只回：好」 | 回复正确 |
| **G1** | 经**默认入口**要 HTML 课件（如「生物 豌豆杂交 HTML」） | **可下载 .html（或可打开产物链接）**；不得仅聊天成功 |
| **G1+** | **同一会话**再要求修改（如「再加 3 道练习题」） | **更新后仍可下载**；不得只改聊天无文件 |
| **G1b**（可选） | 要 DOCX/PPTX | 可下载对应文件 |
| **G2** | 过程可见 | 有步骤/节点/工具，非黑盒一句 |
| **G3** | 运行中停止（若支持） | 停止后状态诚实 |
| **G4** | 故意失败/中断仍要文件 | **不显示成功无文件** |

**阶段 A 出口：** G0、G0b、G1、G1+ 均为 PASS。  
G2/G4 建议同日；G3 视产品能力。

## 默认入口（反花架子）

阶段 A 必须存在一条普通人可进的「课件」对话/应用：系统约束为要文件必须可下载。详见 `ops/PHASE-A-PACK.md` §A5。
