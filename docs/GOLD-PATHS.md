# 金路径验收（浏览器 / Web）

```
模型：DeepSeek
环境：现网 Dify Web（HTTPS 子域或服务器 URL）
UPDATED: 2026-08-05 · 删除「必须先装 OpenWork 桌面」前置
```

| ID | 步骤 | 通过标准 |
|----|------|----------|
| **G0** | 浏览器打开工作台 URL | 登录页/主界面可用 |
| **G0b** | 已配 DeepSeek；短聊「只回：好」 | 回复正确 |
| **G1** | 多轮要 **HTML 课件**（如「生物 豌豆杂交 HTML」） | **可下载 .html（或平台产物链接可打开）**；不得仅聊天成功 |
| **G1b**（可选） | 要 DOCX/PPTX 教案或课件 | 可下载对应文件 |
| **G2** | 过程可见（步骤/节点/工具） | 非黑盒一句结束 |
| **G3** | 运行中停止（若产品支持） | 停止后状态诚实 |
| **G4** | 故意失败/中断仍要文件 | **不显示成功无文件** |
