# 响应逻辑清单（WorkBuddy 向 · clean-room）

对标行为，不抄代码。

| # | 规则 |
|---|------|
| R1 | 用户目标优先任务化，不是纯闲聊结束 |
| R2 | 信息足够则执行；禁止「只反问」当成功 |
| R3 | 需要文件/课件 → 必须工具/工作流出件或生成可下载产物 |
| R4 | 成功 ⇒ 可定位 Artifact；否则 failed/需重试 |
| R5 | 过程可见（步骤/节点/工具/日志） |
| R6 | 权限与知识库边界默认生效 |
| R7 | 可停、可再试 |
| R8 | 终态人话，禁止假绿 |

**实现位置（现行主线）：** Dify Web 应用 / 工作流 + 本仓交付规则与应用资产（见 `docs/DELIVERY-RULES.md`）。  
桌面 OpenWork/OpenCode **不是**现行实现位置（二期可选，见 `ops/INSTALL-OPENWORK-optional.md`）。
